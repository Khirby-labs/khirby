Goal:     Session 4 of the Forms redesign — close the remaining design-system gaps on the list + analytics views and two analytics correctness nits.
Done:     FormsView.vue — status chip now a dot + label with rounded-md (was color-only rounded-full); kind chip and slug code rounded-md; submission count + slug font-mono/tabular-nums; EmptyState "+ Create Form" now calls openCreateModal() (was setting showCreateModal directly, leaking prior state — L1); initial newForm ref copies template fields by value instead of aliasing the shared array (L1). Fixed the concurrent-load race (L5) with a monotonic requestSeq guard so a slow earlier response can't overwrite a newer one. New FormsAnalyticsView.spec.ts (totals render, loading skeleton). Web 60 -> 62 tests / 12 -> 13 files.
Why so:   Kept the analytics filter bar in the page body rather than teleporting it through PageActions — it is a multi-control panel, not a single top-bar action, and forcing it into the top bar would crowd the breadcrumb. Only the manual header chrome (title + back link) was removed, which is what the design rule actually targets on nested routes. Skipped a unit test for the exact UTC boundary output because toISOString() depends on the runner's timezone (brittle in CI); the fix is small and the race/skeleton behavior is what the spec locks.
Failed:   Nothing abandoned. The daily-bar rounded-t and the text-[10px]/[9px] chart labels were left as-is (off-spec but explicitly low-priority in the UI audit, and not color violations so design-guard is clean).
