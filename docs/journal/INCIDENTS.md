# Incidents — traps that bit us, so they don't recur

One entry per trap, in the table below. **Hard pairing rule:** every "Don't" is
paired with a "Do instead" — an unpaired prohibition measurably degrades results.
Write an entry via `/incident` immediately after a trap bites, especially your own.

**Ceiling ~25 active entries.** Above that, promote a recurring trap to the
`AGENTS.md` pitfalls table or a path-scoped rule (closer to where it bites), then
delete the row here. Traps already promoted to `AGENTS.md` (e.g. the Jest DI
`.then`-on-root-db-mock trap, guard name, `/api/` prefix) live there, not here.
